# CyberEquities

Private portfolio site for CyberEquities.com — black-on-black cyber vault showcasing premium domains.

## Run locally

```bash
python3 -m http.server 4321
```

Open [http://127.0.0.1:4321](http://127.0.0.1:4321).

## Experience

- **Desktop:** vertical snap-scroll vault plates — each domain full-viewport with embossed glory + side index
- **Mobile:** horizontal swipe deck + thumb dock (prev/next, live valuation, inquire)

Valuations on site = Afternic × 5.
